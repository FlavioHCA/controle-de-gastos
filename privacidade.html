Política de Privacidade — Controle de Gastos

Última atualização: 28 de outubro de 2026.

O Controle de Gastos é um aplicativo web gratuito e pessoal para organizar receitas, gastos, cartões e dívidas. Esta página explica quais dados o app usa e como eles são tratados.

1. Dados que coletamos

  • Da sua conta Google (ao clicar em "Entrar com Google"): apenas seu nome, e-mail e foto de perfil, usados somente para identificar sua conta no app. O app não acessa seu Gmail, Drive, contatos ou qualquer outro serviço do Google.
  • Dados que você mesmo lança: receitas, gastos, cartões, dívidas e categorias que você digitar no app.

2. Onde os dados ficam

Os dados são armazenados no Supabase (banco de dados na nuvem, região São Paulo). Cada usuário só consegue ler e alterar os próprios dados — o acesso é bloqueado por regras de segurança no banco (Row Level Security).

3. Uso e compartilhamento

Os dados são usados apenas para o funcionamento do app. Não vendemos, não compartilhamos e não usamos seus dados para publicidade.

4. Exclusão dos dados

Você pode apagar seus lançamentos dentro do próprio app a qualquer momento. Para excluir sua conta e todos os seus dados, envie um pedido para o e-mail abaixo.
